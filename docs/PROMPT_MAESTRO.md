# Prompt maestro resumido - MyPredicts

MyPredicts es una plataforma de predicciones financieras. El objetivo es mantener un producto coherente y conectado.

## Propuesta

MyPredicts permite generar predicciones financieras educativas, comprar estrategias con monedas internas y gestionar una suscripcion PRO.

## Modulos activos

- Home publica.
- Auth.
- Predicciones ML.
- Backtesting.
- Portfolio virtual.
- Marketplace de estrategias.
- Wallet y monedas internas.
- Stripe.
- Billing PRO.
- Ruleta.
- Reviews y noticias como apoyo.
- Admin.

## Reglas de producto

- No inversiones reales.
- No brokers.
- No retiradas.
- No dinero real dentro de la plataforma.
- Las monedas son virtuales.
- Stripe se usa para recargas y suscripciones.
- Las compras internas se hacen con monedas.

## Frase defendible

MyPredicts es una plataforma educativa de predicciones financieras con componentes de analisis, gamificacion y marketplace, donde los usuarios trabajan con una economia interna basada en monedas virtuales.
